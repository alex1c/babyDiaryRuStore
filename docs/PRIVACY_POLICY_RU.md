# Политика конфиденциальности — «Гнёздышко — дневник малыша»

**Последнее обновление:** 10 сентября 2026 г.  
**Пакет приложения:** `com.calculatorplatform.babydiary`

## 1. Общие сведения

«Гнёздышко — дневник малыша» — локальный дневник и трекер для родителей. Приложение **не является медицинским сервисом** и не ставит диагнозы. Записи помогают вести личный дневник ухода и не заменяют консультацию врача.

## 2. Какие данные хранятся локально

На устройстве пользователя могут храниться:

- профили детей (имя, дата рождения, фото профиля — по желанию);
- записи сна, кормления, подгузников и пользовательских событий;
- показатели роста и веса, вехи развития, моменты с фото;
- наблюдения о самочувствии (температура, симптомы, лекарства, визиты) — как личные заметки;
- напоминания;
- локальные PDF-отчёты и резервные копии, созданные пользователем.

Эти данные **хранятся локально** в базе SQLite и файлах приложения. Регистрация аккаунта и облачная синхронизация не требуются.

## 3. Когда данные могут покинуть устройство

Данные дневника покидают устройство только при **явном действии пользователя**, например:

- «Поделиться» PDF или текстовой сводкой через системный диалог;
- создание и передача файла резервной копии;
- сохранение/отправка файла через системные приложения.

Разработчик не получает содержимое дневника через эти действия автоматически.

## 4. Реклама (Yandex Mobile Ads)

В приложении используется **Yandex Mobile Ads** для показа баннеров на информационных экранах и редкого interstitial после успешного создания нового PDF.

- Рекламные запросы обрабатывает SDK Яндекса согласно его назначению и политике.
- В рекламные события **не передаются** имя ребёнка, дата рождения, здоровье, лекарства, симптомы, значения кормления/сна, фото и заметки.
- Sensitive формы (активный сон/ГВ, ввод здоровья, backup, обучение) баннерами не перегружаются.

## 5. Аналитика (AppMetrica)

Используется **AppMetrica** (App ID / API key приложения в консоли Яндекса).

Аналитика нужна, чтобы понимать факт использования функций (например: открытие экрана статистики, создание отчёта, завершение обучения).

- В AppMetrica **не отправляются** имя ребёнка, дата рождения, фото, заметки, лекарства, симптомы, температура, вес, рост, объёмы кормления, длительности сна, содержимое PDF и backup.
- Сбои аналитики **не блокируют** работу приложения.
- Отправка статистики может зависеть от сети; офлайн-использование дневника сохраняется.

## 6. Разрешения устройства

В зависимости от функций могут запрашиваться:

- уведомления — для напоминаний, созданных пользователем;
- камера / галерея — для фото профиля, моментов и вложений, которые пользователь добавляет сам;
- доступ к файлам — для выбора/сохранения backup и обмена отчётами.

## 7. Дети и COPPA

Приложение предназначено для **родителей / опекунов**. Данные о ребёнке вводятся взрослым и хранятся локально как часть семейного дневника.

## 8. Изменения политики

Актуальная версия публикуется вместе с приложением и на странице политики конфиденциальности проекта. Существенные изменения отражаются датой обновления.

## 9. Контакты

По вопросам конфиденциальности: через страницу репозитория проекта на GitHub (`alex1c/babyDiaryRuStore`) или контакты разработчика в карточке приложения RuStore.
